# Aulas POO - Java ☕

Repositório criado para armazenar os códigos desenvolvidos durante as aulas de Programação Orientada a Objetos (POO) utilizando a linguagem Java.

## 📚 Conteúdo

Neste repositório você encontrará exemplos e exercícios relacionados a:

- Classes e Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Métodos e Construtores
- Tratamento de Exceções
- Coleções em Java
- Projetos e atividades práticas

## 🛠 Tecnologias Utilizadas

- Java
- VS Code / IntelliJ IDEA
- Git e GitHub

## 📂 Organização

Os códigos estão separados em pastas de acordo com as atividades, listas ou conteúdos trabalhados nas aulas.

## 🎯 Objetivo

Praticar os conceitos de Programação Orientada a Objetos e acompanhar minha evolução no desenvolvimento Java.
